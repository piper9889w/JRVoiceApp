`piper9889w/SIPApp` repository at commit

The source repository did not contain a `LICENSE` file, SPDX identifier, or
GitHub license declaration when it was incorporated on 2026-10-11. Therefore
these files are **not represented as MIT-licensed merely because JRVoiceApp's
new code is MIT-licensed**. Confirm the intended distribution license with the
copyright owner before releasing a binary or redistributing this source.

Imported maintained components: SIP transport and dialog engine,
multi-account registration manager, RTP/G.711 audio engine, SRTP helpers, SIP
target resolver, credential-store adapter, and media capability reporting.
